# Nader Studio

A lightweight, responsive homepage for the Nader Studio organization. The site uses plain HTML and CSS and has no build step, runtime scripts, or third-party assets.

## Files

- index.html — page content and metadata
- styles.css — responsive layout, visual design, and accessibility states

## Preview

Open index.html in a browser. No package installation or build command is required.

## Deployment

The site is a static Vercel project with no build command or output directory. The production branch is main.
